이 파일에 DB 연결 정보와 JWT 시크릿을 설정합니다.

7. 배포는 어떻게 되는지

백엔드 배포 (수동 — 집PC 재빌드)

코드 수정 → cd deploy/local; .\deploy-local.ps1 → Docker 이미지 재빌드 (local-samba-api) → 컨테이너 재기동 → 🏠 집PC 백엔드 (api.samba-wave.co.kr)

프론트엔드 (자동)

git push main → ▲ Vercel 자동 감지 → 프론트엔드 자동 배포

백엔드는 집PC에서 cd deploy/local; .\deploy-local.ps1 재빌드로만 배포됩니다 (라이브=빌드 이미지, 볼륨 마운트·--reload 없음 → 재시작만으론 코드 반영 안 됨). 프론트엔드는 main push 시 Vercel이 자동 배포합니다.

배포 순서 주의: DB 마이그레이션(alembic) → 백엔드(집PC 재빌드) → 프론트엔드(Vercel) 순서로 배포해야 합니다. 순서를 어기면 없는 컬럼/API 참조로 서비스 장애가 발생합니다.
네트워크: 인바운드는 api.samba-wave.co.kr → GCP 정적IP/Caddy → WireGuard 터널 → 집PC samba-api 컨테이너로 들어옵니다.
